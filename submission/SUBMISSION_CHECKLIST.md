## Project Submission Fields

Project name: **CivicLens**

Brief description:

CivicLens is an AI-assisted citizen complaint platform that captures civic issues, understands them with Gemini, detects likely duplicate incidents using location and embeddings, and routes tickets to the responsible municipal department. It provides separate citizen reporting and officer operations experiences.

Successfully implemented features:

- Citizen complaint submission with optional photo evidence
- Browser GPS capture and manual coordinates
- Gemini-based category, severity, summary, hazard, and language analysis
- Deterministic municipal rules and critical-hazard escalation
- Local multilingual embedding generation
- Supabase PostgreSQL/PostGIS/pgvector storage
- Geospatial and semantic duplicate detection
- Incident and operational ticket creation
- Priority assignment and department routing
- Officer ticket queue and status updates
- Analytics summary
- Decision and model audit data
- Responsive React citizen and operations interfaces

Additional features:

- EXIF photo location extraction
- Human-review flags
- Private Supabase Storage bucket
- Gemini fallback for unavailable API/model responses
- Live local backend and frontend integration
